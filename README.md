## 📂 Proyecto destacado

### 🖨️ Copy Express — Aplicación web para gestión de pedidos

Aplicación desarrollada en **Python** con **Streamlit** y **Pandas**, enfocada en organizar y administrar pedidos de una papelería o centro de fotocopiado.

**Funciones principales:**
- Registrar pedidos con datos del cliente y del archivo.
- Configurar cantidad de copias, tipo de impresión y tamaño de papel.
- Calcular automáticamente el precio y el tiempo estimado de entrega.
- Marcar pedidos urgentes y aplicar el recargo correspondiente.
- Consultar, buscar y filtrar pedidos.
- Actualizar el estado de cada pedido: pendiente, en proceso, listo para recoger o entregado.
- Visualizar un resumen de pedidos y valores por estado.

**Tecnologías:** Python · Streamlit · Pandas · JSON

> Proyecto académico ejecutado localmente. Los pedidos se almacenan en un archivo JSON en el equipo donde se ejecuta la aplicación.
